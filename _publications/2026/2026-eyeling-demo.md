abstract: >-
  We introduce <a href="https://eyereasoner.github.io/eyeling/playground" target="_blank">Eyeling</a>, a <a href="https://w3c-cg.github.io/N3/reports/20230703/" target="_blank">Notation3</a>-based tool that brings rule-based reasoning directly to Web applications. <a href="https://eyereasoner.github.io/eyeling/playground" target="_blank">Eyeling</a> allows users to evaluate rules locally, close to where data is accessed, rather than relying on server-side infrastructure. We demonstrate its use for applications such as <a href="https://www.w3.org/TR/odrl-model/" target="_blank">ODRL</a> access control and provide an interactive playground where users can run examples, inspect results, and explore explanations of how conclusions were reached - all directly in the browser.
