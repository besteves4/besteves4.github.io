abstract: >-
  We explore how data sovereignty and trustworthy data use can be supported directly in the browser, without relying entirely on servers to make decisions about how data may be accessed and used. We introduce a comprehensive test suite for the <a href="https://w3c-cg.github.io/N3/reports/20230703/" target="_blank">Notation3</a> rule language, together with <a href="https://eyereasoner.github.io/eyeling/playground" target="_blank">Eyeling</a>, a Notation3-based rule engine that can be run in the browser, designed to ensure that different systems interpret rules consistently. Our evaluation identifies interoperability gaps in existing implementations, while <a href="https://eyereasoner.github.io/eyeling/playground" target="_blank">Eyeling</a> achieves full conformance with the specification. The work demonstrates how semantic technologies and generative AI can complement each other to build reliable, interoperable tools for data governance, legal compliance, and trust in decentralised Web applications.
